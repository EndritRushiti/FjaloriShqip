# FjaloriShqip logo

| File | Use |
|---|---|
| `logo.svg` / `logo-1320.png` | full logo on light backgrounds |
| `logo-white.svg` / `logo-white-1320.png` | full logo on dark backgrounds |
| `logo-mark.svg` / `logo-mark-512.png` / `logo-mark-1024.png` | the "F" mark alone: app icon, favicon, social media avatar |

The PNG files have a transparent background.

## Colours

| Name | Hex |
|---|---|
| Albanian red (mark, "Shqip") | `#c8102e` |
| Red on dark backgrounds | `#ff5468` |
| Text ("Fjalori") | `#1f1b18` |
| Text on dark backgrounds | `#f2ede7` |

## Font

Serif: Palatino Linotype (Windows), Palatino (macOS), Book Antiqua or Georgia as fallbacks.
"Fjalori" is regular weight, "Shqip" and the "F" are bold.

The SVG files use the font installed on the viewer's device, so the letters can look slightly different
on devices without Palatino. For print or official use, use the PNG files, or convert the text to outlines
in a vector editor such as Inkscape (Path → Object to Path).
